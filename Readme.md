# DOCHOC

AI-powered smart study assistant for Smart Education.

## Problem
Students study from scattered notes with no structure, passive revision and
untrustworthy AI tools that exclude low-bandwidth users.

## Solution
- Auto-organized skill-tree folders for uploaded notes
- AI "second brain" that summarizes notes 
- Gamified chatbot quizzes and dynamic flashcards
- Automated visual reports
- Low-bandwidth design, aligned with BIS standards
  (IS/ISO/IEC 40180, 42001, TR 24027)

## Tech stack (planned)
Next.js, Tailwind CSS, LLM API
